# Pete the Pirate

A text-based adventure game where you explore a ship, battle enemies, and collect treasure as the legendary pirate Pete.

## Features

- **Character Creation**: Create your own pirate character with a custom name
- **Exploration**: Explore different rooms and encounter various challenges
- **Combat System**: Engage in turn-based combat with enemies
- **Inventory System**: Collect gold and equipment as you adventure
- ~~**Dynamic Gameplay**: Multiple paths and choices that affect your journey~~
- **Static Gameplay**: One room played over and over again

## How to Run

### Prerequisites
- Python 3.10 or higher

### Clone and Run

```bash
# Clone the repository
git clone https://github.com/yourusername/pete-the-pirate.git
cd pete-the-pirate

# Run the game
python main.py
```
